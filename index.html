Пользовательское соглашение

1. Общие положения

Настоящее Пользовательское соглашение регулирует порядок использования сервиса по приему и обработке заявок на вывоз строительного мусора.

2. Статус сервиса

Сервис не является перевозчиком и не оказывает услуги по вывозу мусора. Сервис выступает как информационный посредник, принимающий и передающий заявки третьим лицам (исполнителям услуг).

3. Принцип работы

Пользователь оставляет заявку через форму (квиз), после чего данные заявки могут быть переданы исполнителю для дальнейшей связи и оказания услуги.

4. Ответственность сторон

Сервис не несет ответственности за качество, сроки и выполнение услуг исполнителями. Ответственность за оказание услуги полностью лежит на исполнителе, который связывается с пользователем.

5. Обязанности пользователя

  • предоставлять достоверные данные при заполнении заявки
  • не отправлять ложные или тестовые заявки с целью злоупотребления
  • не использовать сервис для незаконных целей

6. Обработка заявок

Все заявки обрабатываются автоматически или вручную и могут передаваться третьим лицам для связи с пользователем.

7. Ограничение ответственности

Сервис не гарантирует обязательное оказание услуги конкретным исполнителем и не участвует в договорных отношениях между пользователем и исполнителем.

8. Заключительные положения

Использование сервиса означает согласие пользователя с данным соглашением.
